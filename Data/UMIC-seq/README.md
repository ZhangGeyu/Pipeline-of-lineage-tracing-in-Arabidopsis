Files in this directory are source files required to run the UMIC-seq analysis pipeline and to call mutations from readouts.

The corresponding analysis code can be found in: Pipeline-of-lineage-tracing-in-Arabidopsis/Analysis-pipelines/UMIC-seq/

The files are described below, using Plant 2 as an example:
#### barcode.probe-Plant2.fasta: 
Probe sequence used to identify the position of the sample barcode.
#### barcodes-Plant2.fasta: 
Barcode sequences corresponding to each sample.
#### UMI_probe-Plant2.fasta: 
Probe sequence used to identify the position of the UMI sequence.
#### reference-Plant2.fa:
Reference sequence of the readout.
#### SampleBC_SampleName-Plant2.txt: 
Dataframe containing library information, barcode numbers, and corresponding sample names for parental samples.
#### SampleBC_SampleName_GS-Plant2.txt: 
Dataframe containing library information, barcode numbers, and corresponding sample names for progeny samples.
