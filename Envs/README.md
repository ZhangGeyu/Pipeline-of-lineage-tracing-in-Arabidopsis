# Computational Environments

This folder contains the Conda environment files used in this study.

## UMIC-seq.yml
Conda environment for UMIC-seq data preprocessing, UMI extraction, and clustering.
## GATK.yml
Conda environment for whole-genome sequencing (WGS) mutation calling,

corresponding to the analysis shown in Fig. S6a.

## Analysis-Pipeline.yml

Conda environment for all other analysis steps.
