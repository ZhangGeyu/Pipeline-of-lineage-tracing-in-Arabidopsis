This section is used for the analysis of the plant1 progeny sequencing experiment, which is generated by TA-clone.

## Step 1. combine the sanger-sequencing data to a consensus sequence
This step is used to conbine the Forward / Reverse sequencing of sanger-seq to a consensus sequence
#### Input
The raw sequencing file: Plant1_Progeny_Sanger_seq.fasta
#### Output
Plant1_Progeny_merge_seq.fasta
#### Command
python TA-clone-ConsensusSeq.py

## Step 2. mapping the reads to the reference and Call mutations
#### Input
reference-Plant1.fa
Plant1_Progeny_merge_seq.fasta
#### Output
Plant1_Progeny_merge_seq.mpileup
#### Command
nohup minimap2 -ax map-ont -t 50 reference-Plant1.fa Plant1_Progeny_merge_seq.fasta -o Plant1_Progeny_merge_seq.fasta.bam &

nohup samtools sort Plant1_Progeny_merge_seq.fasta.bam -o Plant1_Progeny_merge_seq.fasta.sorted.bam &

nohup samtools mpileup --max-depth 0 --output-BP --output-QNAME --reference reference-Plant1.fa Plant1_Progeny_merge_seq.fasta.sorted.bam -o Plant1_Progeny_merge_seq.mpileup &

## Step 3. Extract mutation information for each Clone
#### Input
Plant1_Progeny_merge_seq.mpileup
#### Output
Progeny_CallSNP_Plant1.txt
#### Command
python TA-clone-Call-mutation.py

## Step 4. Calculation of Mutation Frequencies in Each progeny Sample
#### Input
Progeny_CallSNP_Plant1.txt
#### Output
MutFreq_In_ProgenySample_Plant1.txt
#### Command
python TA-clone-mutation-freq.py
