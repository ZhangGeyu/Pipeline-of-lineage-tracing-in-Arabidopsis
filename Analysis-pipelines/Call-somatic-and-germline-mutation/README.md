### The code in this directory is used to call mutations from readouts, extract bona fide mutations, and calculate mutation frequencies for each sample.

Codes under the folder "Mutation-for-TA-clone" is designed for Sanger sequencing libraries and is only used for progeny samples of Plant 1.

Codes under the folder "Mutation-for-UMIC-seq" is designed for UMIC-seq libraries and is used for all other samples.
